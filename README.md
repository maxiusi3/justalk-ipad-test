## 在 iPad 上测试

1. 用 Safari 打开网址，建议横屏；微信内请按提示转到 Safari。
2. 先选「不开麦，键盘 / 触屏试玩」，检查开始、选关、触屏按钮和退出。
3. 返回家长入口，阅读语音说明、勾选同意并答题，再进入语音跟读。
4. 检查听到示范后跟读是否被识别，暂停、退出和切到后台后麦克风提示是否消失。
5. 默认使用 iPad 系统录屏。`?record=local` 是另需家长同意的实验入口，不保证 iPad 录制和识别能同时工作。

## 已知边界

- 尚未在真实 iPad 或中国大陆网络完成语音、麦克风中止、录屏、分享及访问速度验收。
- 当前是三首草稿和 TTS 占位；六首正式内容、演唱/伴奏、素材权利、名称和运营信息仍待确认。
- 游戏不上传识别文字、音频或视频，没有远程统计或排行榜。Safari 语音服务可能把音频交给 Apple 处理。
- GitHub Pages 托管方可处理 IP 等访问日志；这与游戏未接入远程统计不同。
- 游戏仅持久保存星级和语音同意；可在家长设置撤回同意、清除进度。
- 旧技术验证页 `/spike/` 不在此站发布，避免绕过家长入口及暴露未验收的诊断数据流程。
